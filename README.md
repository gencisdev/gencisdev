## Como trabalho

- **Mobile-first de verdade:** ecrãs desenhados a 360 px e testados em Android real.
- **Segurança por omissão:** RLS em todas as tabelas, buckets privados, só a chave `anon` no cliente.
- **Tudo em português de Angola:** textos, moeda (Kz) e fluxos pensados para o mercado local.
- **Entrega verificável:** TypeScript estrito, build de produção e CI a cada push.
